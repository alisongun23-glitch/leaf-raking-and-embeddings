# Kinship local-PCA experiment

Tests the proposal in `reports/Local origins in word embeddings.md` (section "An afternoon's experiment")
using the pre-registered word sets, labels and statistical safeguards in
`research_notes/Local origins in word embeddings/experiments_and_pitfalls.md`.

Files:

- `kinship_pca.py` -- the whole experiment in one script (local PCA of the 8 male and 15 mixed-sex kin terms,
  exact / Monte-Carlo permutation tests, leave-one-out stability, frequency-matched random-set null,
  supervised cross-sex transfer, offset collinearity, Linzen-style analogy check, plots).
- `results.md` -- every number in tables, the plots, and a plain-English reading of the predictions.
- `results_tables.md`, `results.json` -- generated by the script (the tables are also appended to `results.md`).
- `pc_scatter_male8.png`, `pc_scatter_mixed15.png`, `evr_spectrum_null.png` -- the plots.

## Rerunning

Python 3.9+ with numpy, scipy, gensim 4.3.x and matplotlib. For example:

```sh
python3 -m venv /tmp/kinship-venv
/tmp/kinship-venv/bin/pip install "numpy<2" "scipy<1.14" "gensim==4.3.3" "matplotlib<3.10"
cd /path/to/RakeLeavesMath
/tmp/kinship-venv/bin/python -I experiments/kinship-pca/kinship_pca.py \
    --gensim glove-wiki-gigaword-300 --out experiments/kinship-pca --seed 0
```

`--gensim NAME` downloads the vectors (376 MB for GloVe 6B 300-d) into `~/gensim-data/` with
`gensim.downloader.load(NAME, return_path=True)`, which fetches the file but never imports the data
directory's `__init__.py`; the file is then read with `KeyedVectors.load_word2vec_format`. Alternatively pass a
raw GloVe text file (`glove.6B.300d.txt`, with or without a header line, `.gz` accepted) with `--vectors PATH`.
The vectors are treated as untrusted data: run the script with `python -I` from outside the data directory and
pass the path as an argument.

Options: `--seed` (default 0; one seed drives every random draw), `--n-random-sets` (200), `--n-mc` (20000
Monte-Carlo shuffles when a label has too many distinct arrangements to enumerate), `--n-dirs` (10000 random
unit directions for the transfer null), `--n-offset-null` (10000), `--max-exact` (500000; labellings up to this
count are enumerated exactly), `--limit N` (load only the N most frequent words, for smoke tests), `--no-plots`.

The full run on the 400,000-word GloVe 6B set takes about 70 s on a laptop, 50 s of which is reading the file.
With the same seed and vector file the output is bit-for-bit reproducible.
